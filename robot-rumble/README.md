# Robot Rumble Arena

Robot Rumble is a two-player, keyboard-first battle game in the CVS Robotics Lab.

- Player 1: `W A S D` to move, `F` to punch, `C` to block.
- Player 2: arrow keys to move, `L` to punch, `P` to block.
- Five clean punches knock out the opponent.
- Blocking works only when the defending robot faces the incoming punch.

The app is a self-contained static page with no build step, server, account, or external game dependency.
