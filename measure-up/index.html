      Instructions, tool model & accessibility

      How to use Measure Up

      Choose a tool, units, difficulty, and mode. Enter a reading with the keyboard or use the large touch controls. Practice Bench can reveal a hint and visually marks the correct feature after a mistake. Timed runs use prepared setups and never change difficulty mid-run.

      Fractions

      Type a mixed number such as 2 3/8, or use the fraction buttons. Equivalent fractions are accepted, so 2 6/16 is also correct. The metric track uses millimeters.

      Dial caliper assumption

      This first release models a 0–6 inch dial caliper with a 0.001 inch resolution, 0.100 inch per dial revolution, and 0.1 inch beam increments. Read the last exposed beam tenth, then add the dial thousandths. Digital and vernier models are reserved for future versions.

      Speed-square language

      The degree setting at the pivot is distinct from the angle of the marked line. Rise/run labels describe slope ratios; they are not degree readings. Advanced roof and stair layout is outside this first release.

      Saved on this browser

      Personal bests are saved only in the current browser/profile. No student account, shared leaderboard, or cloud database is used. Certificates are generated locally from the completed run.

      Keyboard & touch

      All controls are keyboard reachable with visible focus. Answer fields submit with Enter, and buttons and inputs use large touch targets. Use the browser zoom controls if you need a larger view.
