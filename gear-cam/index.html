CNC ROUTER · GRBL

Cut setup

Set the cut order and use values approved for your bit, material, and machine. The G-code button unlocks when the setup is complete.

Cut order

Top profile cuts first. For each line, choose the piece or opening you want to keep. The preview shows the full width reached by the bit. Passes may overlap in waste when the full bit clears the finished edges; one bit diameter of gap is enough.

    Router settings

    Enter the number printed on the bit, then choose its units.

    Final depth: — mm. Enter a pass count or depth per pass; the other value updates. A bottom skin keeps the outline attached to the stock.

    The file uses millimeters (G21) and absolute coordinates (G90). Spindle commands work only when the router is wired for them; start and stop a manual router by your machine procedure.
