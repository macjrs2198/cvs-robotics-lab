# Fiducial artwork provenance

The 21 PNG files in this directory are the recognition-pattern images extracted unchanged from the supplied **Byte to Bite Fiducials** printable. The source sheet identifies IDs 0–20 and its printing instructions establish the numbered edge as the top edge. The full PDF is intentionally not published with the simulator.

The pattern family and IDs were cross-checked against VEX Robotics' official Circle21h7 AprilTag printable and VEX V5 AI Vision documentation. BEST-facing simulator text retains the game term **Fiducial**; sensor help identifies the modeled VEX family. Artwork remains attributed to its supplied BEST Robotics/VEX source material and is included only for this educational simulator.

Runtime geometry keeps the source measurements separate: each cut paper sheet is 8.5 inches square, while the extracted recognition pattern is 550 PDF points, or 7.6388889 inches, square.
